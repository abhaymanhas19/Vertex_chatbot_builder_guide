ACME PRIVATE KNOWLEDGE BASE — API RATE LIMITS
Classification: Internal training sample
Last updated: 2026-07-01

The fictional AcmeDesk Intake API uses request limits per workspace.

Standard plan: 300 requests per minute.
Enterprise plan: 1,200 requests per minute.
Burst traffic can temporarily exceed the average limit, but clients should not depend on burst capacity.

When the limit is exceeded, the API returns HTTP 429 with a Retry-After header. Clients should use exponential backoff with jitter and should respect Retry-After when present.

Repeated immediate retries can extend a traffic spike and make recovery slower. Bulk migrations should be scheduled and tested with a low concurrency setting before increasing throughput.
