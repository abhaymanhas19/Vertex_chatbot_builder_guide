ACME PRIVATE KNOWLEDGE BASE — PASSWORD RESET POLICY
Classification: Internal training sample
Last updated: 2026-08-10

Users can reset their own password from the sign-in page by selecting “Forgot password”. A reset link expires after 30 minutes and can be used once.

Support agents must not manually set a user's password or ask the user to send a password over chat or email. If self-service reset fails, the agent must verify the user's company email address and open an Identity Assistance request.

For accounts protected by SSO, local password reset does not restore access. The user must resolve access with the organization's identity provider administrator. If the SSO configuration itself is failing, route the case to the Identity Platform queue.

Locked local accounts automatically unlock after 15 minutes unless an administrator has placed a security hold on the account.
